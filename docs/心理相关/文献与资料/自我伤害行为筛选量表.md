# 自我伤害行为筛选量表

!!! tip "提示"

    我懒得给这个做在线测试的适配了，各位可以自行答题算分

## 使用说明

使用筛选量表不必利用晤谈，只需将平时对孩子外在行为的观察加以记录、评量即可。

这份量表是希望能找出那些行为表现是需要及时注意的问题，以预防将来不幸事件的发生。

请您根据您所知该生「**最近一个月**」的情况仔细作答，如果有下列情况发生，则在「是」的框框内打勾；如果没有则在「否」的框框内打勾。

## 记分与解释

本量表评估方式采取「是」、「否」的评定，若勾选「是」，则给予一分，计算方式以总和计分，得分愈高，表示自我伤害行为愈多。

**参考值：**

- **国中样本**（1019份）：平均值 7.71，标准差 7.18  
  → 得分 **≥15 分**（比平均值多一个标准差）需加以注意及关心。

- **高中样本**（1132份）：平均值 6.43，标准差 6.28  
  → 得分 **≥13 分** 需多注意并进行防治工作。

| ------- | ----- | ----- | ----- | ----- |
| 忧郁、孤独   | 2.26  | 2.64  | 2.04  | 2.66  |
| 攻击、违纪   | 2.02  | 2.88  | 0.90  | 1.56  |
| 行为改变    | 1.23  | 1.37  | 1.23  | 1.29  |

**预警阈值（得分 ≥ 平均值 + 一个标准差）：**

- **国中生**：忧郁孤独≥5分，攻击违纪≥5分，行为改变≥3分，自残自杀≥1分，退缩自我批评≥4分。
- **高中生**：忧郁孤独≥5分，攻击违纪≥5分，行为改变≥3分，自残自杀≥1分，退缩自我批评≥5分。

> 得分低于参考值并不表示绝对健康，仍需注意行为变化。
